# Cheta Ezenwoye | Portfolio

Static portfolio site served by GitHub Pages at https://ch-ezey.github.io

- `index.html` is the whole site (HTML, CSS and JavaScript in one file).
- `assets/` holds the images and the Continuum Bold web font.
- Sections are routed with the URL hash: `#home`, `#projects`, `#experience`, `#contact`, `#project-<id>`.
